PlotTheme

DeepSpaceTelemetry.PlotTheme — Module
PlotTheme

Plotting standards shared by every figure: the Okabe–Ito semantic palette, the standard figure layout with its uniform print scaling (PlotStyle), the measured legend and figure sizing (figure_legend!, size_to_panels!), and the CairoMakie theme (telemetry_theme). Lengths are Makie units (1/96 inch) at the standard layout, which PlotStyle scales.

source
DeepSpaceTelemetry.PlotTheme.PlotStyle — Type
PlotStyle

Lengths of one figure set, all in Makie units: scale relative to the standard layout, the figure width, the axis heights panel_height and strip_height, the font sizes (fontsize for axis labels and legends, fontsize_tick, fontsize_annotation), the line widths (linewidth for data, linewidth_guide for reference lines and window edges, linewidth_edge for the edge of an area fill), and markersize. PlotStyle(scale) multiplies the standard layout by scale throughout; PlotStyle() is the standard layout itself.

source
DeepSpaceTelemetry.PlotTheme.style_for_width — Function
style_for_width(column_width_mm::Real) -> PlotStyle

The PlotStyle of a figure printed column_width_mm wide (Makie units are 1/96 inch). At 178 mm the axis labels print at ≈ 11 pt and the tick labels at ≈ 9 pt; at the 100 mm floor of the publication export, at ≈ 6 pt and ≈ 5 pt.

DeepSpaceTelemetry.PlotTheme.scaled — Function
scaled(style::PlotStyle, length::Real) -> Float64

length, given in Makie units at the standard layout, at the scale of style. Every absolute length a figure sets by hand — a reserved tick-label width, a gap, an offset — goes through here.

DeepSpaceTelemetry.PlotTheme.annotation_fraction — Function
annotation_fraction(style::PlotStyle, text) -> Float64

Width of the single-line annotation text as a fraction of the axis it sits in, at half an em per character (the mean advance of the text face) against AXIS_WIDTH_SHARE of the figure width, capped at 0.45 — beyond that neither end of the axis is free. Independent of the scale of style. Nothing is positioned with it; annotation_side chooses an end of the axis by it.

source
DeepSpaceTelemetry.PlotTheme.annotation_side — Function
annotation_side(occupied, x_lo, x_hi, fraction) -> Symbol

End of the axis for an in-axis annotation block of relative width fraction (annotation_fraction): :left when one of the occupied x positions (upright rules, shaded edges) lies within fraction of the right edge and none within fraction of the left edge, else :right.

Relative distance between an in-axis annotation block and the axis frame at the end it is aligned to (annotation_anchor).

DeepSpaceTelemetry.PlotTheme.annotation_anchor — Function
annotation_anchor(occupied, x_lo, x_hi, fraction) -> Tuple{Float64,Symbol}

Relative x position and horizontal alignment of an in-axis annotation block of relative width fraction (annotation_fraction) on an axis spanning [x_lo, x_hi], clear of the occupied x positions (upright rules and shaded edges; those outside the axis are ignored). The block with its two insets (ANNOTATION_EDGE_INSET) takes the right end, else the left end, else the middle of the widest interval between consecutive positions; it stays at the right end when no interval holds it.

julia> DeepSpaceTelemetry.PlotTheme.annotation_anchor([0.5, 9.5], 0.0, 10.0, 0.2)
(0.5, :center)

DeepSpaceTelemetry.PlotTheme.power_of_ten_labels — Function
power_of_ten_labels(values) -> Vector{String}

Tick labels with one common power of ten, that of the largest magnitude among values: 1×10ⁿ is written 10ⁿ, zero is 0, a mantissa carries at most three significant digits without trailing zeros, and a negative value takes the typographic minus.

julia> DeepSpaceTelemetry.PlotTheme.power_of_ten_labels([0, 10_000, 20_000, 30_000])
4-element Vector{String}:
 "0"
 "10⁴"
 "2×10⁴"
 "3×10⁴"

DeepSpaceTelemetry.PlotTheme.UpperPrunedTicks — Type
UpperPrunedTicks()

Tick locator of the lower panel of a stacked pair: the ticks of the default locator on the axis range, without those within TICK_PRUNE_FRACTION of the upper limit. A tick label at the upper limit of the lower panel meets the 0 of the panel above across the row gap; pruning it is the stacked-axes rule (matplotlib's prune = "upper"). Passed as yticks = UpperPrunedTicks().

DeepSpaceTelemetry.PlotTheme.line_advance — Function
line_advance(style::PlotStyle) -> Float64

Vertical advance between two lines of in-axis annotation text in Makie units: the line height of the theme's text face (height / units_per_EM, the multiplier Makie applies to multi-line text) times the annotation font size. Places a second text primitive directly under a first, e.g. a plain block below a LaTeX headline.

DeepSpaceTelemetry.PlotTheme.fit_legend! — Function
fit_legend!(legend, available_width::Real) -> Int

Sets legend.nbanks to the smallest row count at which the legend, as Makie itself measures it, is no wider than available_width, and returns that count. A legend whose longest group cannot fit keeps one entry per row.

source
DeepSpaceTelemetry.PlotTheme.figure_legend! — Function
figure_legend!(fig, style::PlotStyle, elements, labels) -> Legend
figure_legend!(fig, style::PlotStyle, groups) -> Legend

The frameless horizontal legend strip above the panels of fig, in as many rows as the figure width requires (fit_legend!). groups is a vector of (title, elements, labels) tuples, one per series family, drawn side by side under bold headers; groups without entries are dropped. Every legend of the project is placed through here.

source
DeepSpaceTelemetry.PlotTheme.size_to_panels! — Function
size_to_panels!(fig, rows::Pair{Int,<:Real}...) -> fig

Fixes the axis height of each listed layout row of fig (row => height in Makie units, e.g. 1 => style.panel_height) and resizes the figure to the height its layout then measures — legend, panels, decorations, gaps, and padding — at the width it already has. Called last, once the legend and every axis are in place.

source
DeepSpaceTelemetry.PlotTheme.save_figure — Function
save_figure(fig, dir::String, stem::String; formats = ("png", "pdf"), suffix = "") -> String

Saves fig as <dir>/<stem><suffix>.<ext> for every extension in formats — PNG at px_per_unit = 4 (≈ 380 dpi at native size), vector formats at native size — and returns the path of the first one. The figure is emptied after the last save: Makie keeps the color buffer of a saved figure, about 70 MiB for a standard PNG, reachable through its scene, so a caller that still needs the figure draws it again.

source
DeepSpaceTelemetry.PlotTheme.figure_scope — Function
figure_scope(f, style::PlotStyle = PlotStyle())

Runs f(), the drawing and saving of one figure, inside a telemetry theme scope of its own (telemetry_theme), runs the garbage collector, and returns the value of f. Makie keeps every figure drawn in a theme scope reachable until the scope ends, about 70 MiB per standard PNG, so a scope around a loop accumulates them (a year of daily session figures exhausted a host); a scope per figure and the release in save_figure bound the loop at one figure. Must not be nested in another theme scope, which would hold the figures.

source
DeepSpaceTelemetry.PlotTheme.telemetry_theme — Function
telemetry_theme(style::PlotStyle = PlotStyle())

The CairoMakie theme of every figure at the scale of style: boxed axes with inward ticks, no titles or minor ticks, a faint dashed grid, guide-weight rules, stroked markers, and frameless legends with top-aligned bold group headers. Faces are (New) Computer Modern via MathTeXEngine; current Makie ignores a plain font = "Computer Modern" and falls back to DejaVu. Tick labels are rotated per axis where they crowd (session HH:MM), not here.
