Sweeps

DeepSpaceTelemetryHeadless.Sweeps — Module
Sweeps

Ensembles and sweeps on the tick clock: the same configuration run over a set of seeds, with optional overrides of scalar keys, and the realized totals of every run gathered into one table. run_sweep drives the runs, serially or several at once on Julia threads; summarize_run reads one run's totals. The products land under <data root>/sweeps/<prefix>/.

source
DeepSpaceTelemetryHeadless.Sweeps.FIGURE_FREE_POST_PROCESSING — Constant
FIGURE_FREE_POST_PROCESSING

The post-processing switches a sweep run sets: no mask timeline, no batch-state raster or session figures, no HDF5 export. The publication export is switched off by sweep_configuration, and run_one runs the mission with figures = false, so no figure is drawn. The gap table and the metrology tables, which the summary reads, are written for every run.

DeepSpaceTelemetryHeadless.Sweeps.require_known_override — Function
require_known_override(key::AbstractString) -> Nothing

Throws an ArgumentError when the dotted key of a sweep override names no key of the configuration schema: a section absent from TelemetryCore.KNOWN_CONFIG_KEYS, a key absent from its section, a key of post_processing.publication absent from TelemetryCore.KNOWN_PUBLICATION_KEYS, a path below a key that is no table, or the post_processing.publication table itself. An array of tables (TelemetryCore.TABLE_ARRAY_KEYS, [[labels]]), which a dotted key cannot address, and [provenance], which the pipeline writes for each run, are refused as well. [payload] takes any key. An override of an unknown key would leave every run on the default while sweep.toml records it as applied.

DeepSpaceTelemetryHeadless.Sweeps.sweep_configuration — Function
sweep_configuration(cfg::AbstractDict, seed::Integer; overrides = String[]) -> Dict{String,Any}

The configuration of one sweep run: cfg on the tick clock (TelemetryCore.tick_configuration), every "section.key=value" override applied, simulation.rng_seed = seed, the switches of FIGURE_FREE_POST_PROCESSING, and the publication export off. An override of a key outside the configuration schema, of an array of tables or of [provenance] is refused (require_known_override). The figures themselves are skipped by run_one.

DeepSpaceTelemetryHeadless.Sweeps.summarize_run — Function
summarize_run(run_dir::String) -> NamedTuple

The realized totals of one run: the counters of the last row of mission_profile.csv, the generated count and the share within the delivery requirement from delivery_delay.csv, the alert-latency medians at 24 h and 72 h (realized and counterfactual) from alert_latency.csv, the hole count of masks/gaps.csv, then pending (undelivered batches not yet due, from the Due column of delivery_delay.csv), discarded (Metrology.discarded_batches), within_requirement_resolved (batches within the requirement over generated − pending + discarded), and the Kaplan–Meier medians alert24_realized_km, alert24_fifo_km, alert72_realized_km, alert72_fifo_km from alert_latency.csv. An absent delay, latency, or gap table, a delay table without Due, or a latency table without the Kaplan–Meier columns leaves its fields missing; a 24 h or 72 h row on which no window completed under both doctrines gives NaN complete-case medians. mission_profile.csv, events_tx.csv, and the run's configuration snapshot are required.

DeepSpaceTelemetryHeadless.Sweeps.run_one — Function
run_one(cfg::Dict{String,Any}, run_id::String, data_root::String) -> String

One sweep run, the body of every member task: the mission headless under data_root, with the console and the global logger silenced; the run's own logs still go to its directory. Returns the run directory.

DeepSpaceTelemetryHeadless.Sweeps.run_sweep — Function
run_sweep(cfg::AbstractDict; prefix::AbstractString, seeds, overrides = String[], workers = 0, data_root = TelemetryCore.DATA_ROOT[]) -> NamedTuple

Runs cfg on the tick clock once per seed in seeds, as <prefix>_seed<seed> under <data_root>/runs/, with the overrides applied to every run (sweep_configuration); with workers > 0 at most that many runs proceed at once as tasks on the Julia threads, and a warning says so when the process has fewer threads; otherwise they run one after another. A run shares no mutable state with its siblings, so its products do not depend on workers. Writes <data_root>/sweeps/<prefix>/summary.csv, one row per run (summarize_run, with the seed first), and sweep.toml, the sweep's provenance: the base configuration's hash, the overrides, the seeds, the package version and source identity (TelemetryCore.source_identity), the date. Returns (summary, dir).
