RunAdapter

DeepSpaceTelemetry.RunAdapter — Module
RunAdapter

Run adapter for consumers: the geometry, batches, payload, arrivals, state, and labeled intervals of the scenario of a run directory, read from the file contract alone (the configuration snapshot, the batch directories, events_rx.csv, label_spans.csv, the lifecycle sentinels), the same way for an active run followed through its arrival feed and for a finished one replayed from it. open_run checks the producer's version against MINIMUM_PRODUCER_VERSION; GapTracker declares the holes of the delivered record as the feeds announce them, with the rules of DeepSpaceTelemetry.Masks.gap_table; declared_holes reads the producer's own feed, holes.csv. The contract is the Analysis Interfaces chapter of the manual; a consumer in another language reads the same files.

DeepSpaceTelemetry.RunAdapter.MINIMUM_PRODUCER_VERSION — Constant
MINIMUM_PRODUCER_VERSION

The oldest producer whose runs the adapter opens by default: 2.1.0, the first to stamp payload_row into the batch metadata, so a batch's rows are exact across generation gaps and emitter restarts.

DeepSpaceTelemetry.RunAdapter.RunGeometry — Type
RunGeometry

The geometry of a run as a consumer needs it: sample_rate [Hz], segment_duration_sec, batch_size (segments per batch), points_per_batch, the mission epoch start_sim_time, the payload_origin (the instant of payload row 1), payload_rows (the length of an external record, nothing for a synthetic payload), the producer's package_version, the clock mode ("wall" or "tick"), and the names columns of the payload columns, from provenance.external_data_columns of the configuration snapshot when present, else the one column TelemetryCore.PAYLOAD_COLUMN_DEFAULT.

source
DeepSpaceTelemetry.RunAdapter.BatchRecord — Type
BatchRecord

One batch of the run: name (LIVE_batch_<k> or ARCH_batch_<k>), its global index k, whether it is live, the payload rows it covers, its content_epoch (the mission instant of its first sample, missing for a batch written before the key existed), and its state — :ground (payload readable), :pruned (delivered, payload removed by the retention custodian), or :lost (retry budget exhausted, payload in lost/).

ArrivalEvent

One row of events_rx.csv: the mission instant sim_time, the batch, the event (:ingested, :retry, :lost, :pruned), and the attempt count the row carries.

DeepSpaceTelemetry.RunAdapter.read_batch — Function
read_batch(run::RunHandle, name::AbstractString;
           column::Union{Integer,AbstractString} = 1) -> Vector{Float32}

The samples of one payload column of one batch, by index or by name, its segments concatenated in ascending segment identifier, from ground/ or, for a lost batch, from lost/ (read_batch_matrix holds every column). DeepSpaceTelemetry.RunAdapter.label_spans — Function
label_spans(run::RunHandle) -> Vector{NamedTuple}

The labeled intervals of the run's scenario from label_spans.csv (2.6.0 and later), (class, type, label, rows, content_start, content_end) with rows a UnitRange{Int} of payload rows: the scenario's [[labels]] spans, the blackout and recovery phases of the link disruptions, the scheduled generation gaps as configured, the contact passes and low-latency periods, and the initial downtime. DeepSpaceTelemetry.RunAdapter.Hole — Type
Hole

A declared hole of the delivered record: its cause (:lost, :pruned, :stream, :scheduled, :recorder, and in the settled feed also :undelivered, :not_generated), the batch for a batch-level hole (missing for a generation gap or the unreached tail), its payload rows, the content interval [content_start, content_end), and declared_at, the mission instant the producer declared the hole at (missing when the tracker derived it from the event logs). Hole(cause, batch, rows, content_start, content_end) builds a hole without a declaration instant.

source
DeepSpaceTelemetry.RunAdapter.GapTracker — Type
GapTracker(run::RunHandle)

The streaming form of the gap table: a cursor over events_rx.csv and events_tx.csv that turns each new lost or pruned row into a Hole at once and each closed gap_start / gap_end pair into one, so a streaming consumer declares a permanent hole the moment the producer does rather than discovering it from the spacing of the content epochs. declare! returns the holes new since the last call; open_gaps lists the generation gaps that have opened and not closed. On a finished run one call declares the same lost, pruned, and generation-gap holes as DeepSpaceTelemetry.Masks.gap_table, except a generation gap still open at run end, which gap_table closes at the mission end and the tracker leaves in open_gaps; the undelivered and unreached rows of that table are end-of-run categories a feed cannot announce.

source
DeepSpaceTelemetry.RunAdapter.declare! — Function
declare!(tracker::GapTracker) -> Vector{Hole}

Reads the rows of both feeds beyond the tracker's cursors and returns the holes they declare, appending them to tracker.declared.

DeepSpaceTelemetry.RunAdapter.open_gaps — Function
open_gaps(tracker::GapTracker) -> Dict{String,DateTime}

The generation gaps announced by a gap_start row and not yet closed, label => start instant: rows from that instant on are not being produced.

source
DeepSpaceTelemetry.RunAdapter.declared_holes — Function
declared_holes(run::RunHandle; after::Integer = 0) -> Vector{Hole}

The declared-hole feed holes.csv (2.6.0 and later) beyond its first after rows, each row a Hole with its declared_at: the file form of GapTracker for a consumer in any language, written by the producer as it declares each hole and settled with the end-of-run holes after the mission phase, so that on a finished run it holds the holes of masks/gaps.csv. Empty when the producer wrote no feed.
