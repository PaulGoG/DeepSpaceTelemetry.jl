RunAdapter

DeepSpaceTelemetryReader.RunAdapter — Module
RunAdapter

Run adapter for consumers: the geometry, batches, payload, arrivals, state, and labeled intervals of the scenario of a run directory, read from the file contract alone (the configuration snapshot, the batch directories, events_rx.csv, label_spans.csv, the lifecycle sentinels), the same way for an active run followed through its arrival feed and for a finished one replayed from it. open_run checks the producer's version against MINIMUM_PRODUCER_VERSION; declared_holes reads the holes of the delivered record from the producer's feed, holes.csv, and delivered_rows the rows on the ground at any instant. The contract is the Analysis Interfaces chapter of the manual; a consumer in another language reads the same files.

DeepSpaceTelemetryReader.RunAdapter.RunGeometry — Type
RunGeometry

The geometry of a run as a consumer needs it: sample_rate [Hz], segment_duration_sec, batch_size (segments per batch), points_per_batch, the mission epoch start_sim_time, the payload_origin (the instant of payload row 1), payload_rows (the length of an external record, nothing for a synthetic payload), the producer's package_version, the clock mode ("wall" or "tick"), and the names columns of the payload columns, from provenance.external_data_columns of the configuration snapshot when present, else the one column TelemetryCore.PAYLOAD_COLUMN_DEFAULT.

DeepSpaceTelemetryReader.RunAdapter.BatchRecord — Type
BatchRecord

One batch of the run: name (LIVE_batch_<k> or ARCH_batch_<k>), its global index k, whether it is live, the payload rows it covers, its content_epoch (the mission instant of its first sample, missing for a batch written before the key existed), and its state — :ground (payload readable), :pruned (delivered, payload removed by the retention custodian), or :lost (retry budget exhausted, payload in lost/).

DeepSpaceTelemetryReader.RunAdapter.delivered_rows — Function
delivered_rows(run::RunHandle; at::Union{DateTime,Nothing} = nothing)
    -> Vector{UnitRange{Int}}

The payload rows on the ground at mission instant at: the rows of every batch with an ingested row in events_rx.csv at or before at (every one when at is nothing), merged into sorted, disjoint intervals. The rows come from the batches' payload_row stamps (batch_rows), so they are exact across generation gaps and emitter restarts. A pruned batch counts as delivered, as its delivery happened; list_batches tells which payloads are still readable.

It replaces the point-wise masks of 2.x (masks/pointwise_mask_*.csv, removed in 3.0), which placed batch k at row (k − 1) · points_per_batch + 1 and were wrong after the first generation gap; on a run without one, the final mask was 1 exactly on these rows.

DeepSpaceTelemetryReader.RunAdapter.label_spans — Function
label_spans(run::RunHandle) -> Vector{NamedTuple}

The labeled intervals of the run's scenario from label_spans.csv (2.6.0 and later), (class, type, label, rows, content_start, content_end) with rows a UnitRange{Int} of payload rows: the scenario's [[labels]] spans, the blackout and recovery phases of the link disruptions, the scheduled generation gaps as configured, the contact passes and low-latency periods, and the initial downtime. DeepSpaceTelemetryReader.RunAdapter.Hole — Type
Hole

A declared hole of the delivered record: its cause (:lost, :pruned, :stream, :scheduled, :recorder, and in the settled feed also :undelivered, :not_generated), the batch for a batch-level hole (missing for a generation gap or the unreached tail), its payload rows, the content interval [content_start, content_end), and declared_at, the mission instant the producer declared the hole at. DeepSpaceTelemetryReader.RunAdapter.declared_holes — Function
declared_holes(run::RunHandle; after::Integer = 0) -> Vector{Hole}

The declared-hole feed holes.csv beyond its first after rows, each row a Hole with its declared_at. The producer appends a hole the moment it declares it and settles the feed with the end-of-run holes after the mission phase, so that on a finished run it holds the holes of masks/gaps.csv. Empty while no hole has been declared (the file appears with the first).

DeepSpaceTelemetryReader.RunAdapter.FeedCursor — Type
FeedCursor(run::RunHandle, feed::Symbol)

A position in one of the append-only feeds of a run, :arrivals (events_rx.csv) or :holes (holes.csv): the byte offset past the last complete line consumed and the count of rows read. Each call of arrival_events or declared_holes on the cursor reads only the bytes appended since the previous call, so following a feed costs O(new rows) per poll, where the after forms re-read the whole file. A line still being written (no terminating newline yet) is left for the next call. No file handle is held between calls, and an absent file yields no rows until it appears.

arrivals = RunAdapter.FeedCursor(run, :arrivals)
while RunAdapter.run_state(run) === :active
    for e in RunAdapter.arrival_events(arrivals)
        # consume e
    end
    sleep(poll_interval)
end
