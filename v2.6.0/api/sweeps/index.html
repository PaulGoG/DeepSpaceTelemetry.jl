Sweeps

DeepSpaceTelemetry.Sweeps — Module
Sweeps

Ensembles and sweeps on the tick clock: the same configuration run over a set of seeds, with optional overrides of any key, each run reproducible to the byte, and the realized totals of every run gathered into one table. run_sweep drives the runs, serially or on worker processes; summarize_run reads one run's totals; the products land under <data root>/sweeps/<prefix>/.

DeepSpaceTelemetry.Sweeps.FIGURE_FREE_POST_PROCESSING — Constant
FIGURE_FREE_POST_PROCESSING

The post-processing switches a sweep run sets: no figures, no point-wise masks, no mask timeline, no HDF5 or publication export. The gap table and the metrology tables, which the summary reads, are always written.

DeepSpaceTelemetry.Sweeps.summarize_run — Function
summarize_run(run_dir::String) -> NamedTuple

The realized totals of one run: the counters of the last row of mission_profile.csv, the generated count and the share within the delivery requirement from delivery_delay.csv, the alert-latency medians at 24 h and 72 h (realized and counterfactual) from alert_latency.csv, and the hole count of masks/gaps.csv. A product that is absent leaves its fields missing.

One sweep run in the calling process: sets the data root, runs the mission headless and silently (its own logs go to the run directory as always), returns the run directory. The body every worker executes.

DeepSpaceTelemetry.Sweeps.run_sweep — Function
run_sweep(cfg::AbstractDict; prefix::AbstractString, seeds, overrides = String[], workers = 0, data_root = TelemetryCore.DATA_ROOT[]) -> NamedTuple

Runs cfg on the tick clock once per seed in seeds, as <prefix>_seed<seed> under <data_root>/runs/, with the overrides applied to every run (sweep_configuration); with workers > 0 the runs are distributed over that many worker processes (started with the active project when fewer exist), otherwise they run one after another in this process. Writes <data_root>/sweeps/<prefix>/summary.csv, one row per run (summarize_run, with the seed first), and sweep.toml, the sweep's provenance: the base configuration's hash, the overrides, the seeds, the commit and version, the date. Returns (summary, dir).
