Export

DeepSpaceTelemetryHeadless.Export — Module
Export

HDF5 product export: the consumer-facing products of a run (event logs, hole feed, metrics profile, batch-state timeline, batch epochs, gap table, metrology tables, markers, label spans, component events) in one self-describing file with the run's provenance as attributes, for analysis pipelines that read HDF5 rather than a directory of CSV files. The CSV products remain the primary interface; the export is a derived, regenerable view of them (export_hdf5). The writer is an extension of the package, loaded with HDF5 (hdf5_available), so that the dependency closure of the package holds no HDF5 binary.

source
DeepSpaceTelemetryHeadless.Export.export_hdf5 — Function
export_hdf5(run_dir::String; path = joinpath(run_dir, "products.h5")) -> String

Writes the run's products into one HDF5 file (default <run_dir>/products.h5, an existing file is rotated to products#k.h5): the tabular products of TABLE_PRODUCTS as column datasets, the batch-state timeline, and the provenance attributes. Times are seconds since the run's start_sim_time with ISO-8601 twins. Returns the file path. Throws an ArgumentError when HDF5 is not loaded (hdf5_available).

source
DeepSpaceTelemetryHeadless.Export.hdf5_available — Function
hdf5_available() -> Bool

Whether the HDF5 writer is loaded: the extension DeepSpaceTelemetryHeadlessHDF5Ext, which Julia loads with the HDF5 package. DeepSpaceTelemetry loads HDF5; the headless package alone does not.

DeepSpaceTelemetryHeadless.Export.TABLE_PRODUCTS — Constant
TABLE_PRODUCTS

(group, relative path) pairs of the tabular CSV products written by export_hdf5, one group each; absent files are skipped.
